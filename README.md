# Yıldızname-i Esrâr

İsim, anne ismi, doğum tarihi, saati ve yerine göre eski müneccimlerin usulüyle yıldızname çıkaran site.
Yapay zekâ kullanmaz: hesaplar (ebced, harf tabiatı, burçlar, menzil, gezegen saati) tarayıcıda yapılır,
yorumlar yazılı yorum kitabından kurallarla seçilir.

- `index.html` — sayfa ve hesaplar
- `kitap-burc.js` — on iki burcun yorumları
- `kitap-yildiz.js` — yedi yıldız, dört unsur, harfler, menziller, esmâ
- `motor.js` — yorumları seçip birleştiren kurallar

Statik bir sitedir; Vercel'de ek ayar gerekmeden yayınlanır.
